# Kiro adapter

Reusable workflow content lives in `.agents/`. This directory contains links to
the shared skills, guidance, hooks, and scripts plus Kiro-specific agent and MCP
registrations under `.agents/adapters/kiro/`.

The same `.kiro` adapter is used by Kiro IDE, Kiro CLI, and Kiro Crew sessions
running the Kiro Agent or Kiro CLI harness.

For setup and pipeline usage, read `.agents/guidance/kiro/README.md`.
