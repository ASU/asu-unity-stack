# GaEventWrapper

`<uds-ga-event-wrapper>` is the web-component equivalent of the React
`GaEventWrapper`. It wraps a single slotted element and wires it for Google
Analytics using the same two mechanisms the design system uses everywhere:

1. **Declarative** — it reflects the values from `gaData` onto the slotted child
   as `data-ga{prefix}-*` attributes, so the CMS/global `[data-ga]` click
   listener tracks it.
2. **Programmatic** — on click it also pushes the event to `window.dataLayer`,
   guarded so it only fires when both `gaData.event` and `gaData.action` are set
   (matching the React version).

It renders no markup of its own — the slotted child keeps its native semantics.

## Usage

```html
<uds-ga-event-wrapper id="cta">
  <a href="/apply">Apply now</a>
</uds-ga-event-wrapper>

<script type="module">
  document.getElementById('cta').gaData = {
    text: 'Apply now',
    event: 'link',
    action: 'apply cta',
    name: 'onclick',
    component: 'hero',
  };
</script>
```

## Do / Don't

### ✅ Do

- Wrap exactly one child element
- Set `gaData` as a property (object), not an attribute
- Use `prefix` when a page tracks multiple element roles (`input`, `header`, `header-input`)
- Let the child keep its own `onclick`/`href` — tracking is additive

### ❌ Don't

- Don't wrap multiple children (only the first is tracked)
- Don't rely on `gaData` push without `event` and `action` — the dataLayer push is guarded
- Don't add presentational styles here (it is a behavioral wrapper)
