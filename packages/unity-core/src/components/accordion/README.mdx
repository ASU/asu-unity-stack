# Accordion

# Accordion

The accordion component organizes content into collapsible sections, reducing
visual complexity and letting users focus on the content most relevant to them.

## Usage

```html
<uds-accordion>
  <uds-accordion-item title="Question 1" open>
    <p>Answer to question 1.</p>
  </uds-accordion-item>
  <uds-accordion-item title="Question 2">
    <p>Answer to question 2.</p>
  </uds-accordion-item>
</uds-accordion>
```

## Default (Single Open)

Only one item can be expanded at a time. Opening a new item automatically
closes the previously open item.

## Properties

### `<uds-accordion>`

| Property   | Type    | Default | Description                           |
| ---------- | ------- | ------- | ------------------------------------- |
| `multiple` | boolean | false   | Allow multiple items open at once     |

### `<uds-accordion-item>`

| Property | Type    | Default | Description                               |
| -------- | ------- | ------- | ----------------------------------------- |
| `title`  | string  | `''`    | Header button text                        |
| `open`   | boolean | false   | Whether the panel is expanded (reflected) |

## Events

| Event                  | Detail           | Description                   |
| ---------------------- | ---------------- | ----------------------------- |
| `uds-accordion-toggle` | `{ open: bool }` | Fired on item open/close      |

## Keyboard Interaction

| Key          | Action                         |
| ------------ | ------------------------------ |
| Enter, Space | Toggle focused item            |
| Tab          | Move to next focusable element |

## CSS Custom Properties

| Property                                     | Default     | Description                  |
| -------------------------------------------- | ----------- | ---------------------------- |
| `--uds-spacing-component-gap`                | `0.75rem`   | Gap between items            |
| `--uds-spacing-accordion-header`             | `1rem 1.5rem` | Header padding             |
| `--uds-spacing-accordion-panel`              | `1rem 1.5rem` | Panel padding              |
| `--uds-color-background-accordion-header`    | `#ffffff`   | Header background            |
| `--uds-color-background-accordion-header-hover` | `#fafafa` | Header hover background    |
| `--uds-color-background-accordion-panel`     | `#ffffff`   | Panel background             |
| `--uds-color-font-dark-base`                 | `#191919`   | Text color                   |
| `--uds-color-border`                         | `#e8e8e8`   | Item border color            |
| `--uds-color-base-bluefocus`                 | `#00baff`   | Focus ring color             |
| `--uds-border-radius`                        | `0`         | Item border radius           |
