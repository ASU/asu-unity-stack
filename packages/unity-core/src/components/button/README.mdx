# Button

The `<uds-button>` component provides a consistent, accessible button across all ASU digital properties. It automatically renders as a `<button>` or `<a>` depending on whether `href` is provided.

## Usage

```html
{/* Standard button */}
<uds-button label="Submit" color="primary"></uds-button>

{/* Link-style button */}
<uds-button label="Learn more" href="/info" color="secondary"></uds-button>

{/* On dark surface */}
<div class="uds-surface-dark">
  <uds-button label="Apply" color="gold"></uds-button>
</div>
```

## Do / Don't

### ✅ Do

- Use `primary` for the single most important action on a page
- Use `secondary` for supporting actions alongside a primary
- Use `gold` for high-visibility CTAs (Apply, Donate)
- Provide meaningful labels that describe the action
- Use `href` for navigation; omit it for in-page actions

### ❌ Don't

- Don't use more than one `primary` button in a section
- Don't use vague labels like "Click here" or "Submit"
- Don't disable buttons without explaining why (use helper text)
- Don't override token values with inline styles
- Don't use `<uds-button>` for toggles or menu triggers (use appropriate components)
